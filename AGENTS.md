# Instrucciones para agentes — MARGOUSH PARTY

- Leer README.md, index.html y estado de GitHub Pages antes de editar. Verificar rama, diff y recursos existentes.
- Este repositorio contiene Chupete Rush, un minijuego; **no asumir que contiene el juego de plataformas MARGOUSH completo**.
- Mantener controles táctiles de arrastre, 30 segundos, idiomas español/francés, música y puntuaciones locales. No afirmar ranking compartido.
- Priorizar Safari iPhone y audio tras gesto del usuario. No confundir prueba de Chromium con Safari físico.
- Cambios incrementales; preservar versiones y recursos. No modificar otros proyectos.
- Publicar pruebas personales mediante GitHub Pages HTTPS con rollback, comprobar el despliegue si las herramientas lo permiten y entregar URL. No entregar solo HTML/ZIP.
- Registrar resultados verificables y pendientes en PROJECT_STATUS.md.
